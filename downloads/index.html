Tablet app for Field Monitors

Android app "SLPHC Field Monitor". Install it on the tablet, sign in once with your username and password while online, then choose your PIN.

Download the app (APK)

Version 0.1.0 · Android 8.0 or newer · about 22 MB

How to install

  1. Open this page on the tablet in Chrome and tap Download the app.
  2. When the download finishes, open it from the notification or from the Files app.
  3. If asked, allow Chrome to install unknown apps, then tap Install.
  4. Open the app, allow Location and Notifications, and sign in.
